# CHANGELOG — bugfix

## 19.10.2026

- **Навык создан** по стоящей процедуре пользователя: свежий baseline-анализ → починка →
  повторный анализ → сравнение двух списков → коммит только когда новых багов нет →
  проверка чистой установки. Первый применённый раунд — `brain-hack-analyze`
  (baseline 5: 1 мажорный, 4 минорных → после: 0, новых 0 → коммит; чистая установка).
- **Два класса багов, которые ловит только прогон чистой установки** (записаны в навык после
  раунда на brain-hack-analyze, harness 18/18 после починки):
  - чтение на импорте артефактов, создаваемых установщиком: файлы `model_setup.py` не в репо,
    и модуль, который читает их на импорте, падает на свежем клоне — навык не деградировал к
    лексикону, а ломался целиком; тесты логики обязаны подменять каталог и обходить проверку
    доступности, а модуль — отвечать честный `unavailable`;
  - загрязнение глобального `sys.path` плагином: поздний импорт в том же процессе берёт модуль
    из домашней папки автора, а не из копии. Тест проходил отдельно и падал в полном прогоне —
    порядкозависимое падение является доказательством общего изменяемого состояния, а не
    сломанного теста.
- Проверка навыка: `py_compile` не считается проверкой — после правки скрипта обязана быть
  одна read-only живая проверка; закреплённые числа тестов не являются фактом, писать
  фактическое число падающих по прогону.
